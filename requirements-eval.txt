#    pip install -r requirements.txt
#    pip install ragas==0.4.3 datasets==4.8.5 pandas==3.0.3
#    pip install --no-deps "pyarrow==19.0.1"
#
#  L'ultimo comando ri-forza la pin Windows-safe: datasets 4.8.5
#  funziona a runtime con pyarrow 19.0.1 nonostante il vincolo
#  dichiarato (verificato: la valutazione RAGAS gira correttamente).
#
#  Questo file e' a scopo documentativo: NON usare
#  "pip install -r requirements-eval.txt" (fallirebbe il resolver).
